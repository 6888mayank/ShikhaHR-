- React 19 + Vite 8
- Tailwind CSS 4 (@tailwindcss/vite)
- Framer Motion 13
- Lucide React

## Run
```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # production -> dist/
npm run preview
```
